# Sketch 替代能力与验收矩阵

基线：本机 Sketch 2026.3.1（234013），2026-11-05 观察；详细能力同时参考官方文档。表中阶段是 openSketch 的建议交付顺序，**所有实现目前均未开始**。

| 能力 | 首次交付 | 达到替代所需的行为 |
|---|---|---|
| 本地文档、多窗口、页面 | M1 | 新建/打开/保存/另存；多个页面；关闭时准确判断未保存内容 |
| 工作区与多 Frame | M1 | 同页多个画框、嵌套、裁剪、跨框移动；缩放和平移不改变文档坐标 |
| 形状、图片、文字 | M1 | 保持类型与可编辑性；修改尺寸不把矢量源永久栅格化 |
| 选择、图层树、变换 | M1 | 多选、锁定/隐藏、重排/编组、旋转/翻转、重复、复制粘贴 |
| 对齐、参考线、测距与吸附 | M1–M2 | 嵌套与旋转对象行为一致；屏幕距离阈值不随缩放漂移 |
| 钢笔和节点编辑 | M2 | 开闭路径、增删节点、直线/曲线、柄联动、节点多选、撤销 |
| 布尔与遮罩 | M2 | 并/差/交/异或保留操作数；孔洞/填充规则正确；可恢复编辑 |
| 样式与颜色 | M2–M3 | 多填充/描边、渐变、阴影、圆角；共享文字/图层样式及颜色变量 |
| 文字专业能力 | M1–M3 | 中英文输入法、富文本范围、段落、行高、字距、自动/固定尺寸、缺字提示 |
| 组件/Symbol 与覆盖 | M3 | 创建定义/实例；文字与样式覆盖；嵌套实例；修改定义正确传播 |
| Stack 与响应式尺寸 | M3 | 横纵布局、间距、padding、对齐、Fixed/Fit/Fill、pinning；文字变化触发布局 |
| 高级布局 | M4/后续 | wrap、min/max、隐藏占位、绝对定位子项与嵌套冲突规则 |
| 导出与切片 | PNG 在 M1，SVG/PDF 在 M2，批量在 M3 | 画框/选择/切片导出；1x/2x/3x；支持对象保持矢量；降级有报告 |
| `.sketch` 迁移 | M0 开始样本研究，M2–M4 递增 | 分版本/特性报告支持；基础对象、组件与布局分别验证；源文件保留 |
| `.sketch` 写回 | 后续单独评估 | Sketch 重开、结构/视觉/编辑行为一致；明确未知字段与版本处理 |
| 本地组件库 | M3 基础/M4 扩展 | 文档内组件管理后再支持跨文档引用、版本和更新冲突 |
| 原型演示 | 本地设计 Beta 后独立评估 | 连接、热点、滚动、覆盖层、转场及预览，不只是一张播放截图 |
| 开发交付 | 基础数值/资源在 M3，扩展后续 | 尺寸、间距、颜色、字体和资源可获取；布局到代码按支持规则映射 |
| 插件、脚本与 MCP | 核心稳定后 | 统一命令 API、事务与权限边界；不默认兼容 Sketch 插件运行时 |
| 多人实时协作与云库 | 后续独立项目 | 冲突解决、权限、同步、版本历史、离线恢复与服务运维 |

Sketch 当前文档覆盖 [矢量编辑](https://www.sketch.com/docs/designing/vector-editing/)、[Frames](https://www.sketch.com/docs/designing/frames/)、[Stacks](https://www.sketch.com/docs/designing/stack-layout/)、[Symbols](https://www.sketch.com/docs/symbols-and-styles/symbols/)。官网可能随新版本更新；本机目标版本应固定，最终以对应版本的实际文档和交互回归为准。

## 三道产品验收门槛

1. **矢量 Alpha：** 从零完成一个简单界面；路径和文字保存重开仍可编辑；可导出 SVG/PDF。完成这一阶段还不足以宣称替代 Sketch。
2. **本地 UI 设计 Beta：** 三页真实界面使用共享样式、组件和 Stack；调整文字与画框尺寸后依然可工作；撤销、文件恢复和常用键盘操作可靠。
3. **已有项目迁移：** 约定的 Sketch 项目集导入后，逐项对比对象语义、视觉结果与编辑行为。公布通过和不支持的特性，不以 ZIP 可读取或预览相似代替验收。

性能、稳定性、缺失字体、色彩管理和辅助功能均跨阶段执行。开源发布验收还要包含可复现构建、独立签名配置、来源许可及干净环境安装；本次评估不代表这些检查已通过。
