# 页面列表、画板容器与缩放控件

用户直接要求优化页面、画板容器、图层右键操作和缩放控件。本阶段基于 `1c845e2`，沿用原分支工作区执行。

- 页面选项改为左侧垂直列表，当前页使用主题选中态；保留添加入口，页面多时列表独立滚动，最多显示约 5 行高度，图层列表仍有空间。切页先结束输入、清空图层选择，切换本身不产生文档历史。不新增页面删除/改名/排序。
- 图层行右键菜单增加“复制图层”“删除图层”，移除侧栏底部复制/删除按钮。右键未选行只作用于该行，右键已选成员作用于已有多选；菜单预检不改变选择，动作执行先结束输入。锁定/隐藏或缺失选择不允许部分执行。
- 原生标题栏右侧用连续滑条替代 100% 按钮，保留适合、缩小/放大入口和菜单 ⌘0。范围为既有 5%–800%，采用 log2 空间，100% 位于可用中段。拖动期间浮层实时显示整数百分比，松开隐藏；以画布中心为缩放锚点，底栏百分比、滑条与滚轮/捏合/切文档同步，不使文档变脏。没有 Canvas 宿主时仍安全设置有限缩放值。
- 画板 frame 已有 children、世界变换、裁剪与树显示；跨容器拖放此前明确未实现。本次普通画布移动达到 3 屏幕点后允许改变归属：释放时采用最后一次成功显示的拖动指针位置确定可编辑画板（未应用的 mouseUp 坐标不单独触发改归属）（重叠时最上层子树优先，再取最深 frame），无目标时从画板移到页面根。忽略选中子树作为目标，拒绝循环；画板本身移动不自动嵌套。选中父子只处理最外层根。
- 每根最近的画板祖先与目标相同时保持原父亲，避免普通组内移动拆组；最近画板祖先和目标均为空也保持原父亲。跨画板才把根插入目标 frame 最上方，按原绘制顺序稳定追加。多选原子执行；包含 frame 的选择整体只移动、不自动改归属。
- 改归属保持当前世界位置、旋转、尺寸、UUID 和子树，旋转父/目标也适用。目标/源有效根及祖先锁定隐藏时拒绝；验证结果格式限制。一次鼠标拖动（位移+归属）只增加一次历史，Escape 整次取消；键盘微调、尺寸调整及单纯点击不改归属。
- 移动中显示临时目标轮廓，松手/取消/结束输入清理，参考线、预览不写入文档或导出。移动出旧画板时可用未裁剪的选中外框表示当前位置，最终归属只在 mouseUp 应用。

不增加自动布局、创建画板时自动收纳、侧栏拖拽重排、画板自动嵌套或 Space 绕过。Sketch 参考：https://www.sketch.com/docs/designing/frames/ （容器与拖放概念参考，不声称完整行为一致）。

验证：Core 几何/层级不变式、原生输入/历史测试、真实 GUI 页面列表/右键/滑条/画板拖入拖出和保存重开，明确区分持键/拖动中视觉的宿主测试证据。更新 Release 前刷新并原生保存用户最新文档；最后恢复，数据不入 Git。
