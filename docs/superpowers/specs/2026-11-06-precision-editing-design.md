# 精准编辑设计

延续用户已授权的下一阶段开发，在图层组织与排版之后补齐 M1 的选择与定位工作流。比较图像/SVG 互操作、组件/自动布局和精准编辑三个方向后，采用精准编辑：能直接服务已实现的基本图形、编组和对齐命令，不引入资源格式或布局模型迁移。

## 范围与交互

- 选择工具从空白区域拖动形成框选矩形。完全包住对象可见 frame 几何包围盒时选中，不是相交即选；小于 3 个屏幕点的移动视为点击。普通框选替换选择，Shift 框选追加，Escape 恢复开始前选择；整个过程不改变文档或历史。
- group 是一个选择单位；frame 完全被框住时选中容器，否则继续检查孩子。隐藏/锁定节点及其后代不可框选。祖先 frame 的裁剪用变换后的凸四边形求交；完全裁掉的节点不参与，部分裁剪按剩余 frame 几何的包围盒。不以实际路径轮廓或描边外扩为框选依据。
- 画布获得键盘焦点时，方向键按页面坐标移动所选根 1 点，Shift 为 10 点，与缩放无关。旋转父容器下用逆变换换算局部位移。选中父子只移动最外层根；任一有效根或其祖先不可编辑时整次移动拒绝。普通文字输入仍由原生文本控件处理。
- 同一段方向键按住/重复事件形成一次历史事务，最后一个方向键松开提交；Escape 取消。开始鼠标手势、切换工具/文档、失去画布焦点或其他主动命令先提交。无变化不产生历史。
- 移动对象时，将整个有效选择的世界 frame 包围盒的左/中/右及上/中/下锚点，与其他可见对象的对应轴锚点比较。排除所选子树及其祖先；可见锁定对象可以作为参考。参考对象的包围盒考虑祖先 frame 裁剪；移动选择使用完整 frame 包围盒。
- 每轴选择最小绝对修正量，阈值为 6 个屏幕点除以 zoom；同距离按绘制顺序及锚点顺序稳定决胜。X/Y 可分别吸附，每轴最多一条参考线。以鼠标按下时的文档和原始拖动位移重新求值，避免累积漂移。
- 默认开启每文档会话的“吸附”开关，底部与网格并列，AX ID `view.snapping`。Control 拖动临时绕过吸附。参考线只在有效移动手势中绘制；结束、取消或切换文档后消失。缩放/平移或改变吸附开关先结束当前手势，避免视口跳变导致位移错误。

## 架构与边界

新增 `CanvasEditing` 纯值 API 负责框选几何、吸附结果和页面轴向平移。几何遍历、变换和裁剪只依赖 Foundation/CoreGraphics；不改变 v1 文件模型。`EditorSession` 持有吸附会话状态；CanvasView 持有临时框选、参考线和键盘事务状态。把精准编辑帮助函数放在独立扩展中，现有 Canvas 输入入口只负责路由。

平移对全部有效根先验证有限位移及结果局部坐标在 ±1e9 内，再一次性返回候选文档；越界或无效选择抛错，不留下部分移动。画布每帧不编码整份文档。保存仍由 DocumentCodec 权威验证。

不在本阶段扩展调整尺寸吸附、绘制吸附、网格吸附、手动参考线、距离数值、编组整体缩放、自动布局、图片/SVG 导入。保持亮暗主题、原生标题栏、编辑区裁剪、文字创建及多文档生命周期。macOS 15+、Swift 6、无第三方依赖；在 `feat/native-prototype` 原工作区继续，不安装到 `/Applications`、不推送。

## 验收

Core 覆盖嵌套旋转、裁剪多边形、group/frame 选择单位、锁定/隐藏、父子选择归一化、两轴/边缘/中心吸附、稳定决胜、空选择/零位移/越界和多缩放阈值。UI 使用原生 NSEvent 验证框选开始/取消/追加、键盘重复的一次撤销、焦点/切换文档收尾、输入字段保护、Control 绕过和覆盖层清理。最终执行完整测试、Release 构建、签名/Info.plist 验证；真实窗口验证框选、微调、吸附、取消、撤销重做及保存重开，并恢复用户文档。
