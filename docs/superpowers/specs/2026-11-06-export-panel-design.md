# 资源导出面板

用户要求继续下一阶段开发。承接已明确延后的右侧导出区域，本轮将现有文件菜单 PNG/PDF 导出扩展成可选择范围和倍率的资源导出流程。基线 `3a2a523`，继续现有 feature 分支。

## 产品行为

右侧检查器末尾增加“导出”分区，沿用亮色 Sketch / 暗色 Compositor 配色，提供范围（当前选择、当前页面）、格式（PNG、PDF）、PNG 倍率（1×、2×、3×）、预计尺寸及“导出…”按钮。当前没有选择时解析为页面导出，不能点击空的选择导出；有选择时默认导出选择，用户可主动选页面。设置按文档会话独立，不进入文档格式或撤销历史。锁定只限制编辑，不禁止导出；隐藏内容按可见性过滤。

PNG 输出为透明背景，保留图层本身的填充；显示最终像素宽高。PDF 使用原有矢量绘制，固定 1×，显示点尺寸。倍率不改变文档几何。文件菜单 PNG/PDF 与面板共享规划和输出路径，菜单固定相应格式，使用当前文档的范围/倍率设置。

选中单一画板沿用已有行为：去掉画板在页面上的位置和旋转，以自身尺寸导出并裁剪内容，作为独立画板资源；不继承外层容器裁剪/透明度。其他单选、多选或编组按画布世界变换导出一个合并文件，保留所选子树和必要祖先的旋转、裁剪与透明度，去掉未选兄弟及祖先自己的填充/描边；父子重复选择不重复绘制。祖先仅负责变换/裁剪，不扩大导出 bounds。旋转裁剪的 bounds 可以是保守包围盒，实际像素仍遵循准确的裁剪路径。无选择的当前页面沿用可见内容范围，空页沿用页面尺寸。

导出前完成画布与检查器输入，并创建不可变内容快照，再显示 NSSavePanel。面板期间的文档/选择切换不能改变将要写出的内容。取消不写文件、不改文档或保存地址；成功在底栏显示文件名，失败显示已有原生错误提示。默认文件名来自单层或页面名称，多选使用“选中图层”；PNG 非 1× 增加 @2x/@3x。文件名必须是单个合法文件名，替换分隔符/控制字符并限制 UTF-8 长度。

PNG 按实际输出像素检查最长边 16,384、总像素 64,000,000，必须在分配 bitmap 和整数转换前拒绝非有限尺寸/倍率、无效范围或超限值。现有 PDF 尺寸边界保留。选择无有效可见目标、完全被裁剪或无效选择时显示清晰原因并禁用按钮，不静默导出页面。PDF 不受 PNG 倍率影响。

## 范围

本轮不包含 SVG、切片工具、多个导出预设、批量文件、多页 PDF、缩略图预览或持久化到文档的 export settings。不改变 `.opensketch` v1。

参考 [Sketch 导入导出说明](https://www.sketch.com/docs/designing/importing-and-exporting/) 的检查器导出设置及图层/画板导出入口；具体支持范围以上述本项目规则为准。

## 验收

使用真实 PNG 解码像素与尺寸、PDF 页框与绘制检查，覆盖 1×/2×/3×、非原点/小数边界、旋转与嵌套、父裁剪/透明度、选择去重、兄弟排除、锁定/隐藏、空选择、最终像素上限。集成验证当前文档路由、原生输入提交、SavePanel 期间切换与取消无写入、无新增脏状态/历史。完成完整测试、Release 和签名检查，再通过真实应用导出 PNG/PDF 并检查产物；用户当前设计先保存并在更新后恢复。
