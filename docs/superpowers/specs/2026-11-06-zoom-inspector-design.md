# 缩放与检查器优化

用户提供 Sketch 检查器截图，要求缩短缩放滑条、提供缩放下拉选项、点击缩放图标显示当前比例，并参照截图优化右侧布局与参数拖动。沿用当前 macOS 原生实现、亮色 Sketch / 暗色 Compositor 配色及多文档结构。

## 缩放

- 滑条从 160 pt 缩至 96 pt，保留 5%–800% 对数范围。
- 在同一控件中显示当前整数百分比与下拉箭头；菜单提供“适合画布”“实际尺寸（100%）”及常用倍率。原独立“适合”按钮并入菜单。
- 百分比常显，点击放大/缩小立即同步；拖动仍显示悬浮比例。不产生文档修改或撤销记录，按当前文档路由，保持视口中心锚点。
- Sketch 官方参考：https://www.sketch.com/docs/interface-and-settings/the-mac-app-interface/the-canvas/ （100% 为 ⌘0，适合全部图层为 ⌘1）。

## 右侧检查器

- 保持 260 pt 固定侧栏及滚动容器，顶部显示图层名称及精简对齐/分布操作。
- X/Y、宽/高分别双列排列，旋转、透明度、圆角采用同样的浅灰圆角数值控件，按布局、样式、填充、边框、文字分区。沿用现有编组/层级、裁剪、字体及颜色功能。
- 仅展示已实现的模型属性；本轮补充现有模型的透明度编辑。编组宽高保持只读。导出面板、约束、自适应布局、阴影、效果留待后续。
- 所有可编辑数值支持键盘输入和标签区域水平拖动；默认每点 1 单位，Shift 每点 10 单位，Option 每点 0.1 单位。鼠标悬停显示拖动提示及水平调整指针。拖动超过 3 pt 才开始修改；相对开始值计算，回到原点不漂移。
- 拖动实时预览，松开一次提交，Escape 恢复开始值；切换选择/页面/文档、窗口失焦、保存/撤销等边界结束编辑，不能跨文档写入或留下悬空历史事务。
- 现有有限值/范围限制继续生效；锁定/隐藏节点及祖先不允许编辑。拖动与直接输入使用一致的校验路径。

## 验收

针对缩放当前文档同步、菜单路由和尺寸，数值边界、单步撤销/重做、Escape、上下文切换、保存与输入焦点做行为测试。完成完整测试和 Release 构建、签名检查，再通过真实 GUI 检查布局、菜单与拖动；记录机器测试和 GUI 验收的边界。用户已有文档先保存，不丢弃。仅本地签名提交，不推送或安装系统目录。
