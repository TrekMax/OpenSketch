# 左侧页面与图层重命名

基线 `08b9adf`。页面行缺少右键菜单，图层右键菜单缺少重命名；现有名称字段可持久化，无需修改 v1 格式。

在页面和所有图层行增加“重命名”，图层包括画板、编组、矩形、椭圆、文字、路径。用户所称组件在本轮指图层树对象，不新增 Symbol 模型。用户明确要求在对应名称位置直接编辑：原行文本变为原生 NSTextField，预填并选中原名，Enter 确认、Escape 取消、点击别处提交，不弹出窗口。

名称只改右键点击的对象，不批量重命名多选成员，不切换页面或改选择。锁定/隐藏不限制名称这种组织元数据，几何及锁定/显示值保持不变。开始前完成原有 Canvas/Inspector 输入；草稿保存在会话中但不写入文档；确认只产生一次撤销，同名不污染 dirty/redo。取消不产生重命名历史。全局 finishInput 同时提交行内草稿，保证保存、撤销、切换页面/文档、工具操作的边界一致；迟到的原生回调通过请求 ID 隔离。

请求捕获文档 ID、页面 ID、对象 ID 和原名。提交前验证对象仍属于原页面、文档仍匹配、名称未被其他操作修改；不依赖当前选择。拒绝空白、内部控制字符和超过现有格式字节限制的名称；保留中文/emoji，修剪首尾空白。先校验候选文档，再提交历史；无效输入保留原名并通过既有底部消息说明。原生编辑器尊重输入法 marked text，确认组合文字前不拦截 Return/Escape。

测试覆盖右键目标语义、全部节点种类、嵌套与锁定/隐藏、Unicode、undo/redo、无效/过期请求、待输入事务和保存重开；真实窗口验证页面/图层/编组右键、输入/取消/撤销。保留用户最新设计，使用独立样例。只做本地 Signed-off-by 提交及 build 应用更新，不安装系统目录或推送。
