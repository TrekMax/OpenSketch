# 左侧页面与图层重命名

基线 `08b9adf`。页面行缺少右键菜单，图层右键菜单缺少重命名；现有名称字段可持久化，无需修改 v1 格式。

在页面和所有图层行增加“重命名…”，图层包括画板、编组、矩形、椭圆、文字、路径。用户所称组件在本轮指图层树对象，不新增 Symbol 模型。使用原生风格的 SwiftUI sheet，预填原名，Enter 确认、Escape/取消关闭。选择 sheet 而非新增行内编辑器，以复用原生输入及明确的确认/取消边界，不扩大焦点管理代码。

名称只改右键点击的对象，不批量重命名多选成员，不切换页面或改选择。锁定/隐藏不限制名称这种组织元数据，几何及锁定/显示值保持不变。打开前完成原有 Canvas/Inspector 输入；草稿不写入文档；确认只产生一次撤销，同名不污染 dirty/redo。取消不产生重命名历史。

请求捕获文档 ID、页面 ID、对象 ID 和原名。提交前验证对象仍属于原页面、文档仍匹配、名称未被其他操作修改；不依赖当前选择。拒绝空白、内部控制字符和超过现有格式字节限制的名称；保留中文/emoji，修剪首尾空白。先校验候选文档，再原子地提交历史，错误在 sheet 中显示。

测试覆盖右键目标语义、全部节点种类、嵌套与锁定/隐藏、Unicode、undo/redo、无效/过期请求、待输入事务和保存重开；真实窗口验证页面/图层/编组右键、输入/取消/撤销。保留用户最新设计，使用独立样例。只做本地 signed 提交及 build 应用更新，不安装系统目录或推送。
