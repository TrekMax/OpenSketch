# 多文档与单次绘制实施计划

> 按用户确认的行为直接实施，使用 executing-plans 顺序执行并按 verification-before-completion 验证。

**目标：** 新建/打开文档不替换其他文档；一次绘制后恢复选择工具。

**架构：** 保留单个原生窗口，新增工作区管理多个独立 `EditorSession`，标题工具栏提供可滚动标签。当前文档决定所有菜单命令、检查器和导出目标。外观为应用级共享设置。

**技术：** Swift 6、AppKit、SwiftUI、Swift Testing；macOS 15+，无新增依赖。

## Task 1：单次绘制

- [ ] 在 `Tests/OpenSketchUITests/SingleCreationTests.swift` 用实际 CanvasView 鼠标事件验证矩形/椭圆/画板创建一次后切回选择，第二次空白点击不新增；文字完成或取消编辑后切回选择；Escape 取消拖动不留下图层。先运行观察失败。
- [ ] 修改 `CanvasView.swift` 的创建、mouseUp、文字结束和取消路径。只结束本次创建工具，用户显式改选其他工具不被后续清理覆盖。一次图形创建对应一次撤销。
- [ ] 运行定向测试与已有画布/文字回归。

## Task 2：工作区与关闭事务

- [ ] 新建 `DocumentWorkspace.swift`：`EditorDocument` 包含稳定 ID、独立 session 和未命名文档名；`DocumentWorkspace` 管理有序文档、当前 ID、新建、打开、切换和关闭。
- [ ] 新建 `WorkspaceTests.swift`：验证多个未保存文档的新建/切换不丢数据，选择/缩放/历史独立，相同文件再次打开选中现有标签，关闭取消或保存失败保留所有待关闭文档。先以最小接口观察行为测试失败，再实现。
- [ ] 关闭前结束活动输入；逐一收集保存/不保存/取消决定，全部同意后才移除文档。保存成功只标记对应文档；退出中途取消保留此前选择不保存的文档。
- [ ] 关闭最后文档生成新的空白会话供下次打开窗口，控制器隐藏窗口。新建命令从隐藏窗口恢复这个空白会话。其他情况下新建总是新增标签。

## Task 3：原生应用集成

- [ ] 新建 `DocumentTabsView.swift`，包含可访问的切换/关闭按钮、完整文件名提示、未保存标记和溢出滚动。
- [ ] 修改 `AppController.swift`：菜单与原生工具栏使用当前 session；新建/打开/示例新增文档；打开面板和 Finder 多文件事件逐个处理；重复打开不覆盖已有编辑。`⌘W` 关闭当前标签，窗口关闭/退出处理全部文档。
- [ ] 修改 `EditorRootView.swift`：根据当前稳定 ID 切换视图；切换前提交文字，保留每个 session 的页面、选区、缩放与平移。窗口尺寸变化同步标签栏宽度。
- [ ] 保存/另存为在弹窗期间绑定确定的文档，拒绝覆盖另一个已打开文档的路径。原生文字撤销继续走 NSTextView 的 UndoManager。
- [ ] 扩展集成测试验证新建和菜单命令路由、标签切换后撤销与导出对应当前文档。

## Task 4：交付验证

- [ ] 完整 `swift test`、Release 构建、plist/严格签名验证、`git diff --check`。
- [ ] 真实窗口验证连续新建三个文档，分别绘制、切换、撤销，关闭取消保留文档，保存/重开独立文档；验证松开绘制后空白点击不新增，文字输入完成后恢复选择。
- [ ] 记录 GUI 实际结果和受环境阻塞的检查；更新 README 和验收记录，进行只读代码复查，限定文件本地提交，不推送。

此处“组件”按用户描述指创建的图形/文字对象，不扩展为 Symbol 组件系统。多独立窗口、标签拖拽重排、自动恢复和其他 0.2 功能另行推进。
