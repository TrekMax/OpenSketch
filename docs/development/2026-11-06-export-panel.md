# 资源导出面板

2026-11-06，基线 `3a2a523`，在 `feat/native-prototype` 延续开发，将先前检查器阶段暂缓的导出面板落地。产品范围为当前选择或当前页面的单文件 PNG/PDF；PNG 提供 1×/2×/3×，PDF 保持矢量及原始点尺寸。

## 导出核心

`8de6500` 增加值类型 ExportSnapshot，保留选中子树及必要祖先变换、裁剪和透明度，移除祖先自身填充/描边及未选兄弟。父子同选不重复绘制，结构祖先不扩张选区范围。单画板按自身尺寸独立导出，位置与旋转归零、强制裁剪；页面范围沿用现有可见内容边界。锁定图层允许导出，无效或完全不可见的选择有明确错误。

PNG 预览和输出共享尺寸校验；倍率同时应用于位图像素和绘图变换。向上取整后的最长边不超过 16,384，总像素不超过 64,000,000，在转整数及分配前拒绝非法值。小数尺寸额外裁剪逻辑导出边界，避免向上取整的尾端漏入区域外内容。PDF 沿用矢量渲染，倍率固定为 1。

默认文件名来自图层或页面名称，多选为“选中图层”；替换分隔符和控制字符，保留中文及 emoji，basename 最多 200 UTF-8 字节。PNG 非 1× 使用倍率后缀，PDF 不带倍率。

核心定向测试 `swift test --filter 'ExportTests|IntegrationTests'` **55 项通过**。测试检查实际解码 PNG 的尺寸、颜色、透明度及小数边缘，PDF mediaBox，嵌套旋转/裁剪、父级透明度、父子同选、隐藏/锁定/无效 ID、模型不变与尺寸上限。RED 阶段暴露并修复小数裁剪边缘、emoji ZWJ 和截断文件名尾部空格问题。

## 集成与验收

`96db8e9` 在检查器属性分区之外添加独立导出分区。每个文档会话记忆范围、格式和 PNG 倍率；不进入文档值或撤销历史。无选择时解析为当前页面，显式页面范围不因选择改变；PDF 隐藏倍率控件并显示点尺寸及 1×，保留先前 PNG 倍率。

正式 root 回调捕获发起文档 ID。菜单和检查器共用 AppController 导出动作：完成原生检查器与 Canvas 输入，准备不可变内容/选项快照，再打开 SavePanel，最后原子写入文件。测试在目的地回调同时修改图层、选择、选项和活动文档，验证导出仍来自原快照；原实现的 PNG/PDF 两个尺寸断言均曾失败。取消只提交原有待结束输入，不增加导出历史、不改变文档 URL。

受影响测试 **66 项**通过；完整 **UI 197 + Core 79 = 276 项 / 16 suites**通过；Release **11.33 秒**，无编译 warning/error。日志 `/tmp/opensketch-task2-{focused,full,release}.log`。打包日志 `/tmp/opensketch-export-96db8e9-package.log`，Info.plist、严格签名验证通过。
