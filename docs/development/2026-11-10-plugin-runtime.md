# M3 插件管理器运行状态接入

## 已实现

- 应用控制器持有共享 `PluginManagerModel`，窗口关闭重开后仍保留任务和设备状态。
- `PluginLibrary` 将导入包复制到 `~/Library/Application Support/OpenSketch/Plugins`，通过原子写入 `registry.json` 保存安装与启停状态。重启时重新验证包并重建 `PluginRegistry`；损坏或缺失的包保留错误条目。
- 更新保留禁用状态；卸载只移除宿主管理的副本；禁止外部包替换内建插件标识，原生文档格式始终启用。
- 插件信息、任务记录、审计记录、设备预览四个页面，提供错误展示、卸载、刷新、任务取消和中英文文案。
- 应用导出入口校验插件启用状态，成功和失败写入任务历史。
- 审计页面聚合当前打开文档的 `pluginAuditEvents`，显示操作、时间、插件来源及批准/未执行状态。
- 本地只读后端支持连接、断开、重连、主动同步当前页面，显示真实 PNG 渲染图及快照版本；同步捕获发起文档，使用可取消任务，发布前检查取消状态。

## 当前边界

- 外部插件完成安装、注册与状态管理，尚未执行外部入口代码。
- 本地预览是宿主内的显示后端，手动同步页面；尚无网络发现、手机端 App 或自动增量推送。
- AppKit 渲染阶段同步执行，取消在阶段边界检查；现有文件导出记录完成/失败，不提供中途取消。
- 任务历史只保留在本次应用运行中；审计记录来自当前打开文档会话，尚未持久化。
