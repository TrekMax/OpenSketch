## 实现与范围

- Core 以纯值命令实现编组/取消编组、上移/下移一层、置顶/置底、六种对齐及双轴等间距分布。原节点 UUID 和子树保持不变，失败不返回部分修改。
- EditorSession 统一预检和执行，有效变更只提交一次文档历史。进行中的文字输入先结束，无效或无变化命令不增加脏状态。
- 原生“图层”菜单、侧栏右键菜单和检查器共用命令；快捷键为 `⌘G`、`⇧⌘G`、`⌘]`、`⌘[`、`⇧⌘]`、`⇧⌘[`。普通文本输入获得焦点时，图层菜单不抢占快捷键。
- 图层树父行先于子行、同级从前到后显示，可展开/折叠；Shift 点击切换成员。右键未选中图层时命令针对该行，右键当前多选成员时保留多选。
- 画布普通点击选择最外层 group，Option 点击保留最深命中；frame 保持子层选择行为。组内文字双击选中文字，并使用现有检查器编辑回退。
- 编组允许移动、旋转和改名；宽高为独立只读属性，不绘制缩放手柄，不显示填充/描边编辑。

详细选择归一化、同父约束、旋转变换和编码校验语义见 [Core API](core-api.md)。

## 真实窗口工作流

使用独立验收文档，未修改用户原设计内容。以下是实际执行结果，不以单元测试代替：

1. 原生绘制三个宽度不同、横向间隔不等、纵向不齐的矩形。画布 Shift 多选后，检查器显示“已选择 3 个图层”，对齐/分布按钮可用。
2. 点击“顶对齐”和“水平等距分布”。A/B/C 的 frame 从 `(19,109,100,100)`、`(219,184,150,150)`、`(519,59,100,100)` 变为 `(19,59,100,100)`、`(244,59,150,150)`、`(519,59,100,100)`：顶部相同，间隙均为 125，水平两端不变。

4. 拖动整组使 X/Y 均增加 50；一次 `⌘Z` 恢复原位置，一次 `⇧⌘Z` 恢复移动结果。`⇧⌘G` 取消编组，三个子层 UUID 保持不变，页面坐标分别为 A `(69,109)`、B `(294,109)`、C `(569,109)`。
5. 先选择 A，再右键未选中的 B 并执行“置于顶层”。检查器转为 B，侧栏顺序变为 B/C/A，底到顶数据为 A/C/B，A 的坐标保持不变。
6. 更新到 `778913e` 后，侧栏 Shift 点击从一个成员增加到两个，再移除回一个，继续增加到三个；按钮能力随选择数更新。此项验证了真实 SwiftUI Button 收到的事件修饰键，而不仅是会话帮助函数。
