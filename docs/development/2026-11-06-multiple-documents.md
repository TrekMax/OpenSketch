# 多文档与单次绘制更新

基于 `42bf501`，实现用户确认的两个优化：新建/打开保留已有文档，一次绘制后返回选择工具。保持 macOS 原生窗口及 Compositor 风格的外观和标题工具栏。

## 单次绘制

矩形、椭圆和画板在完成一次绘制后切回选择；文字在完成或取消行内编辑后切回选择。点击文字编辑区域外先结束编辑，再按选择工具处理，不继续插入第二个文字对象。Escape 取消尚未完成的拖动。结束旧操作时不会覆盖用户已明确选择的新工具。

一份图形创建仍对应一次撤销。文字保持已有的“创建对象”和“编辑文字”两个事务；取消文字编辑回到创建时的内容，不删除已创建的对象。

## 文档工作区

`DocumentWorkspace` 保存有序的 `EditorDocument`，每份文档拥有独立 `EditorSession`、稳定标签 ID 和未命名编号。内容、页面、选区、工具、缩放、平移、撤销与保存状态独立。重复打开规范化后的相同路径或符号链接别名会切换到已有文档，保留未保存编辑。

关闭多个文档时先结束输入，按标签顺序询问保存/不保存/取消；全部通过后才移除文档。途中取消或保存失败会保留此前已选择“不保存”的文档。已经成功写入磁盘的保存不回滚，其对应文档保持已保存状态。

关闭最后文档后创建全新的空白占位会话。隐藏窗口后的 New/Open 消费此占位；普通显示状态下 New 总是追加标签。打开失败保留现有文档。
