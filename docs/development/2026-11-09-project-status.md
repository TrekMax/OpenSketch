# OpenSketch 项目完成进度与验收状态

日期：2026-11-09。当前基线为 **0.1.0 原生初始原型**。本页集中记录已完成内容、自动化验证和仍待确认的边界；后续路线与插件平台设计见[开发路线与插件平台规划](../roadmap.md)。Compositor 相关实现的独立重写审核见[独立重写审核](2026-11-09-original-rewrite-audit.md)。

## 已完成范围

### 编辑器与文档

- 原生 AppKit 画布、SwiftUI 面板、原生 `NSOutlineView` 图层树。
- 单窗口多文档标签、页面添加/切换、页面和图层选择。
- 画板、编组、矩形、椭圆、文字和路径值模型。
- 选择、框选、移动、右下角缩放、方向键微调、复制、删除和单次创建后返回选择工具。
- 编组/取消编组、四种叠放顺序、六种对齐、水平/垂直等间距分布。
- 画板作为容器，支持图层拖入、拖出、跨画板移动及保持世界几何。
- 图层树整行选择、Shift/Command 多选、展开折叠、拖拽排序、容器放入、移回页面根层级和原位重命名。
- 显示/锁定控制、撤销/重做、连续拖动合并为单次事务、Escape 取消和脏状态管理。

### 画布、文字与检查器

- 缩放、平移、适合窗口、100%、网格和锚点缩放。
- 移动吸附、临时绕过吸附、参考线和框选。
- 检查器中的坐标、尺寸、旋转、透明度、填充、描边、圆角和文字排版编辑。
- 原生 `NSTextView` 行内文字编辑，支持 Unicode、中文、emoji 和缺失字体回退。
- 绘制、文字测量和 PNG/PDF 导出使用共享的文字布局与变换规则。

### 文件、导出与设置

- `.opensketch` 目录包、`document.json`、稳定 UUID、有序子节点和版本化格式。
- 保存前校验、有限制的输入读取和原子包替换。
- PNG 1×/2×/3× 导出、PDF 导出、选择/画板/当前页面范围和超大输出保护。
- Sketch 文件仅做元数据检查，不声明可编辑导入或无损往返。
- 亮色、暗色、跟随系统；English、简体中文、跟随系统；设置持久化和即时刷新。
- 应用菜单、图层菜单、右键菜单、检查器和原生窗口生命周期已接入当前编辑事务。

## 仍待确认的原型边界

- 原生图层树真实鼠标拖放的最终人工验收，包括多选拖动、排序、容器反馈、撤销和保存重开。
- 窄窗口布局、手动拖动中途 Escape、独立 Dock/Finder 重开、原生颜色面板和输入法候选窗口。
- macOS 15 实机运行；当前主要验证环境为 Apple silicon / macOS 27.2。
- 大文档 GUI 响应、可见范围裁剪、内存和帧率；现有几何基准不能替代这些测试。

## 当前明确不支持

- 完整贝塞尔控制柄联动、布尔运算、渐变、多重填充、完整描边效果和完整 SVG 互操作。
- 组件实例、共享样式、Stack 自动布局、约束、切片、批量导出和开发交付包。
- Sketch 可编辑导入、自动恢复、实时协作、云端资源库和生产签名。
- 插件运行时、插件化格式导出、MCP/AI 原生操作、设备同步预览、HTML 交互导出和素材包导出。

这些不支持项已经纳入后续规划，但不应被当前 0.1.0 原型的完成进度隐含承诺。

## M2 开发状态

M2 已启动，第一项路径基础能力已完成初版：

- 新增 `PathEditing` 核心操作，支持路径点规范化、开放/闭合路径、直线追加/插入、直线转贝塞尔曲线、节点/贝塞尔控制点移动、单个/多个节点删除和序列校验。
- 画布新增钢笔工具（`P`）和节点编辑初版：支持连续点击创建开放路径、拖拽创建贝塞尔曲线、Enter 完成、双击闭合、双击路径进入节点编辑、拖动节点、Shift 多选、Option 双击插入节点、Delete 删除节点和 Escape 取消；路径使用现有文档模型、撤销、保存、命中测试和导出链路。
- 布尔运算已完成 Core 几何后端和基础图层菜单/检查器命令接入；当前结果是可恢复的路径快照。
- 渐变填充已完成基础数据模型、格式校验、画布渲染、命中测试和 PNG/PDF 共用渲染链路；检查器渐变编辑和更丰富的描边效果仍待完善。
